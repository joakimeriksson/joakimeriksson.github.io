# joakimeriksson.github.io

Personal landing page, served at <https://joakimeriksson.github.io/>.

A single static `index.html` — no Jekyll, no theme, no build step. The
`.nojekyll` file tells GitHub Pages to publish the files exactly as committed.

Project sites live under this one on their own paths, deployed from their own
repositories:

| Path | Repository |
|---|---|
| `/` | this one |
| `/ai-smarthome/` | `ai-smarthome` — side projects, synths, SID tracker |

`resources/` holds Leshan LwM2M demo server builds and is served as-is.

To edit the page, edit `index.html`. Copy, layout and a small light/dark palette
are all in that one file.
